Course Enrollment by Department

Task 1 · Rectangle area = number of students

Hierarchical data A treemap needs a parent → child structure, so the flat CSV rows are reshaped into University → Department → Course.
The root First we design a root node. Here the root is the whole University.
sum() & sort() sum() calculates the total value of every parent node from its children. sort() arranges the nodes, biggest first.
round(true) Rounds all the rectangle coordinates to whole numbers so the edges look crisp.
Drawing the rectangles join("g") creates one <g> element per course, and translate moves each group to its own coordinates.

Pakistan Flight Route Network

Task 3 · Link thickness = flights per week · Circle size = number of routes · Drag cities, hover to highlight routes

Nodes from edges There is no city list in the CSV, so we build it from the source and target columns.
Degree A city's degree is how many routes touch it. Bigger degree = bigger circle.
Scales One scale maps flights/week to link thickness, another maps degree to circle radius.
Force simulation Links pull cities together, charge pushes them apart, so the layout settles by itself.
Try it Drag any city, or hover one to light up its routes while everything else fades.

World Population Choropleth

Task 4 · Darker country = more people · Hover a country for details

Joining the data The CSV id (country code) is matched to each map feature's id, so every country finds its own population.
Projection + path The projection turns lon/lat into x/y. d3.geoPath then turns each country's shape into an SVG path.
Square-root scale A few giants (China, India) would wash out everyone else on a linear scale. The sqrt scale spreads the colors out more fairly.
Light gray = no data Countries missing from the CSV are painted light gray instead of looking like "zero".
Hover The country gets a dark border and a tooltip with its name and population.

Pakistan's Largest Cities

Task 5 · Circle area = population · Labels for cities above 1 million

Mercator, centered geoMercator().center(...) plus a scale zooms the map in on Pakistan.
Longitude first! projection([lon, lat]) — it takes longitude then latitude, the opposite of how we usually say coordinates.
Area, not radius People read area, so the radius uses a sqrt scale. Double the population = double the area.
See-through circles Semi-transparent fills keep overlapping cities visible.
Labels vs tooltip Only cities above 1 million get a label. Hover any city, even a small one, to see it.

Cities, Population & Flight Routes

Task 6 · Four variables on one map · Hover a city to highlight its routes

Matching routes Each route's source and target city name is looked up in the cities file to get its coordinates.
Draw order Routes are drawn first and cities after, so circles sit on top of the lines.
Four encodings Position = location, size = population, color = hub or not, line width = flights per week.
What is a hub? A city with 4 or more routes. Count comes from the flights file.
Hover Hover a city to light up its routes and dim everything else.
